学习 Obsidian 的新特性

最近几个月，Obsidian 推出重大功能比较多：

  1. Obsidian CLI
  2. Obsidian Base

第一个其实相当有用，因为未来可能不必直接启动 Obsidian 了，直接可以在命令行操作自己的知识库，当然，在 EA 阶段我也找过一些平替，例如：Obsidian CLI 的替代，甚至还自己写过 utils/250706-obsidiantools-query-data.py，只是最后放弃了，这太麻烦了。

接下来，Base 是我比较喜欢的功能，因为他几乎就是相当于 Notion 的表格，Logseq 的查询，一些简单的场景，他可以替代 Dataview，其实之前开源社区也有一个类似的 插件，只不过不知道为什么后面陷入了无限停更，两个东西非常相似，以至于我认为其实 Obsidian 只是把他嵌入了进来。

所有的 index 重命名为 README

主要考量还是 GitHub 排版问题，未来有一天 GitHubPagse 消失，那么GitHub的可读性上就至关重要了，从 README 到 index 重命名这件事情当然可以交给脚本。只是这项变动可能较多，需要借助脚本完成。
