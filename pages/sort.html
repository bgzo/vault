3. 简单插入排序

从第二个元素开始，依次比较大小，小的去前面，大的去后面，采用的方式是最低效的平移数组，针对于基本有序的数列很高效。

4. 希尔排序 → 缩小增量

作为插入排序的改进版,，先分组进行排序使得数列基本有序，再用插入排序进行排序。

10. 桶排序 (Bucket)

CPP stl 库的 Set 天然自带排序功能：

方法效果
begin()返回 set 容器的第一个元素的 地址

快速排序

Worst-case running time

cn+c(n−1)+c(n−2)+⋯+2c

=c(n+(n−1)+(n−2)+⋯+2)

=c((n+1)(n/2)−1)

=c(2n(n+1)​−1)≈c(n2)

c 表示完成一次交换需要的时间

Best-case running time

Θ(nlog2​n)

(Theta, left parenthesis, n, log, start base, 2, end base, n, right parenthesis)
